# Ø's Handy Dandy Toolbox
A bunch of tools I may need or not need in my day to day...
All in one Place

## WHOAMI
Hi, I'm Luvlørn, hence the Ø (Slashed 0) in the title, I'm an indie dev, still in high school, various Informatics Olympiads participant, member of HackClub, and with my latest project: The creator of Ø's Handy Dandy Toolbox!

## But like... why? What does it do?

Very simple.. So I describe myself as a dude who does a lot of stuff, so that causes me to have very little time for literally anything. So, what does that have to do with my website? Since I do a lot of stuff (All of this including coding, making music, photography, web and graphic design, math, etc.) I need a bunch of tools. But I always get stressed when I have to look in different websites and download a few million tools just to convert some images or audios. So, the purpose of the website is just to have everything in one place... Made by me.

And a big plus... No ads, no trackers, no cookies, no nothing. Just plain old HTML, some CSS to make it pretty and simple JavaScript scripts that just do what they are told.
Because who doesn't hate those ugly ads and trackers that sell the info you upload to the website right?
I mean who doesn't like their privacy? But oh well, there's my open source project haha.

## Usage of AI in this Project

Part of [HackClub: The Game](https://game.hackclub.com/)'s TDLR and submission guidelines, it's made very clear that the use of AI is permitted up to 30% of the project, and it has to be reported in this README.md file.

For this project I used AI to only make the first tool of the website which is the Image Cropper. I coded the HTML and the CSS but I didn't know how to code the script section as I'm not very experienced in JavaScript, so I asked AI to code it for me and based on the code it gave me, I used it as a base and inspiration to learn to do the rest of the scripts myself.
